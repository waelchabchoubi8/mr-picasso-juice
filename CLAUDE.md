# Soltana Pro Max — Claude Context

Traditional Tunisian canned-food store for **Sfax, Tunisia** (mloukhiya, kleya, chakchouka, ojja, couscous…). Red & white brand palette (matches the logo).

> History: this project began as "Mr. Picasso Juice". Many filenames keep juice-era names (`JuiceMenu.tsx` = food catalogue, `PicassoPalette.tsx` = coffret builder). The brand is now **Soltana Pro Max**.

## Commands

```bash
npm run dev      # Start dev server → http://localhost:3000
npm run build    # Production build
npx tsc --noEmit # TypeScript check (run before reporting done)
```

## Stack
- **Next.js 15** App Router (Server + Client components)
- **React 19** — no class components except ErrorBoundary
- **Framer Motion 12** — animations, springs, variants
- **next-intl 3** — i18n, FR default / EN secondary
- **Tailwind CSS 3** — utility-first, custom tokens in `tailwind.config.ts`
- **NO WebGL / Three.js** — removed for performance

## PWA (installable app)
- **Manifest**: `src/app/manifest.ts` → auto-served at `/manifest.webmanifest`, link auto-injected by Next.
- **Icons**: generated by `scripts/gen-icons.mjs` (pure Node zlib, no deps) — red→gold gradient + white tin can. Re-run after changing the design. `public/icon.svg` is the vector source.
- **Logo**: components (`Navbar`, `Footer`, `LoadingScreen`) display `public/logo.png`. Replace that file with the real brand logo (square works best).
- **Service worker**: `public/sw.js` — network-first navigations, cache-first assets. **Registered in production only**; in dev it's unregistered (would cache HMR chunks → stale bugs).
- **Install UX** (`InstallPWA.tsx`): floating pill bottom-left (WhatsApp is bottom-right). Android/Chrome → native `beforeinstallprompt`. iOS → guided "Add to Home Screen" modal (Safari has no prompt API). Hidden when already installed (standalone) or dismissed (7-day cooldown, localStorage `picasso-pwa-dismissed`). Navbar mobile menu fires `window` event `picasso:open-install`.
- **Meta**: `viewport.themeColor` + `metadata.appleWebApp`/`icons` in `[locale]/layout.tsx`.
- **Note**: PWA installs to the home screen (fullscreen), not a literal `.apk`. A real Play Store `.apk` needs a TWA wrapper (PWABuilder/Bubblewrap) — separate build step.

## Key patterns

### Always run tsc before finishing
```bash
npx tsc --noEmit
```

### Trig hydration fix (CRITICAL)
Never use `Math.cos/sin` inside JSX render — always pre-compute at **module level**:
```ts
const LINES = [0,60,120].map(a => {
  const r = (a * Math.PI) / 180;
  return { x: Math.round(Math.cos(r) * 10) / 10 };
});
```
Prevents server/client float mismatch in SVG attributes.

### FM12 + React 19 ref pattern
Put `ref` on plain `<div>`, NOT on `<motion.div>`:
```tsx
<div ref={anchorRef} className="...positioning...">
  <motion.div style={{ x, y }}>...</motion.div>
</div>
```

### Adding new sections
1. Create component in `src/components/`
2. Add strings to `messages/fr.json` AND `messages/en.json`
3. Import in `src/app/[locale]/page.tsx`
4. Use responsive padding: `py-16 lg:py-28 px-4 sm:px-6`

### i18n locale switching
```tsx
import { useRouter, usePathname } from '@/navigation';
router.push(pathname, { locale: 'en' });
```

## Cart

### CartItem shape
```ts
{ id, name, format, price: number, qty, color, fruits?: string[] }
```

### Adding items from a new component
```tsx
import { useCart } from './CartContext';
const { addItem, openCart } = useCart();
addItem({ id: 'unique-id', name, format: 'Label · size', price: 7.5, color: '#hex' });
```

### Cart item IDs
- Catalogue items: `${categoryId}-${itemName}` e.g. `"mijotes-Mloukhiya"`
- Coffret (box): `coffret-${size}-${dishIdCounts}` e.g. `"coffret-15-mloukhiya3-harissa2"`. The box composition is stored in the `fruits?: string[]` field (reused), e.g. `["3 × Mloukhiya", "2 × Harissa"]`, shown joined by ` · `.
- Same id → qty increments instead of duplicate entry

### Mobile + button visibility
Menu `+` buttons use `opacity-100 sm:opacity-0 group-hover:opacity-100` — always visible on mobile, hover-only on desktop.

### iOS input zoom fix
Use `text-base sm:text-sm` on all `<input>` inside CartDrawer to prevent iOS Safari zoom (16px min).

## Prices (TND)
- Conserves (catalogue): ~5.5–10 TND per tin/jar (hardcoded in `JuiceMenu.tsx` CATALOGUE)
- Coffret boxes (`BOXES` in `PicassoPalette.tsx`): 10 tins = 75, 15 = 105, 20 = 130 TND (bulk discount)
- Delivery: pickup free · Sfax/national +7 TND (`DELIVERY_FEE`) · national min 30 TND (`NATIONAL_MIN`)

## Currency / Region (CRITICAL)
- **All prices in code are stored in TND** (the base). Foreigners see **EUR**. Conversion + formatting happen at *display* time only — the cart, totals and the national-delivery minimum always work in TND, so order logic never breaks.
- `CurrencyContext.tsx` — `region: 'tn' | 'intl'` → `code: 'TND' | 'EUR'`. Persisted in localStorage `soltana-region`. Rate: `EUR_PER_TND = 0.30`.
- **Opening flow**: on first visit, after the loader, `RegionGate` asks "Tunisia (Dinar) vs Abroad (Euro)" — animated, with **Ali** (`left.png`/`right.png`) waving on both sides. Choice is remembered → gate is skipped on return visits. Region can be changed anytime via the **Navbar currency switcher** (desktop + mobile menu).
- **Using it in a component**: `const { amount, symbol, code, price, convert } = useCurrency();`
  - `amount(tnd)` → number only ("9,500" / "2,85"), `symbol` → "TND"/"€", `price(tnd)` → full string. Render as `{amount(x)} <span>{symbol}</span>`.
  - Pure helpers `formatAmount/formatPrice/convertAmount/currencySymbol(tnd, code)` exist for non-hook contexts (e.g. the WhatsApp message builder, which takes `code` as a param).
- **Never hardcode `TND`/`€`** in JSX — always go through the hook so the switch is reactive. The WhatsApp order message shows the chosen currency; for EUR it also appends the TND equivalent on the total line for the merchant.
- `RegionGate` uses `mix-blend-multiply` on the Ali photos to drop their light background into the cream backdrop (cut-out look). All decorative offsets are module-level precomputed (hydration-safe).

## Ordering (CartDrawer)
3-step wizard: cart → method → details. Methods: **pickup** (2 stores), **Sfax** delivery (≤10 km, +7 TND), **national** delivery (all of Tunisia, +7 TND, min 30 TND). Canned food ships everywhere — there is NO product eligibility restriction (the old juice "1L-only" guard is neutralised: `ineligible` is always `[]`).
